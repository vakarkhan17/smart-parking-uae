# Smart UAE Parking Web/PWA

## Run locally
npm install
npm run dev

## Important
Edit src/main.jsx and replace GOOGLE_MAPS_API_KEY with a Google Maps JavaScript API key.

Enable:
- Maps JavaScript API
- Places API
- Geocoding API

## Render Static Site
Root Directory: smart-parking-web
Build Command: npm install && npm run build
Publish Directory: dist
